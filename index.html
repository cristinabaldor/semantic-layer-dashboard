How to read this page

Ready

A metric is ready when it ships in Cube today and returns production data. A dimension is ready when the catalog marks it as covered in Cube.

Not ready yet

Partly in Cube: some of it exists in Cube. Needs Cube work: the data is in a mart and needs adding to Cube. Needs data work first: the data has to be built in dbt before Cube work can start. Dimensions marked stays in Tableau are display helpers and are not counted.

Transition stage

    Fully transitioned

    The dashboard is launched on Cube and every one of its metrics is ready. A launched dashboard with open metrics is flagged.
